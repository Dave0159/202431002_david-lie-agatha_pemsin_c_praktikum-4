## Overview
This project involves building a machine learning model to classify drugs based on patient data. The classification is performed using the **Gaussian Naive Bayes** algorithm. The code explores the dataset, preprocesses categorical features, trains the model, and evaluates its performance using confusion matrices and classification reports.

## Dataset
The project utilizes the dataset provided in the file **drug200.csv**. 

The dataset contains the following 6 features:
*   **Numerical Features:** `Age`, `Na_to_K`
*   **Categorical Features:** `Sex`, `BP` (Blood Pressure), `Cholesterol`, `Drug` (Target Variable)

## Libraries Used
The following Python libraries are required to run the notebook:
*   `pandas`: Data manipulation and analysis
*   `numpy`: Numerical computations
*   `matplotlib.pyplot`: Data visualization
*   `seaborn`: Statistical data visualization (used for the confusion matrix heatmap)
*   `scikit-learn`: Machine learning tools (`LabelEncoder`, `train_test_split`, `GaussianNB`, metrics)

## Workflow
1.  **Data Loading & Exploration:** The data is loaded using pandas. Basic information and statistical descriptions of the dataset are extracted.
2.  **Data Preprocessing:** Categorical features (`Sex`, `BP`, `Cholesterol`, `Drug`) are converted into numerical values using Scikit-Learn's `LabelEncoder`.
3.  **Data Splitting:** The feature set (`x`) and target labels (`y`) are split into training and testing sets (75% training, 25% testing) with a fixed random state for reproducibility.
4.  **Model Training:** A `GaussianNB` (Gaussian Naive Bayes) model is instantiated and fitted to the training data.
5.  **Evaluation:** The model makes predictions on both the training and testing datasets. Performance is evaluated using a classification report (precision, recall, f1-score) and visualized via a confusion matrix heatmap.
